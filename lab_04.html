1. Working with files

Python provides a built-in open() function to open a file. Its most important arguments are:

  • the string file: the path to the file to open, i.e. its name, optionally preceded by the directory;
  • the string mode: the mode in which the file is opened;
  • the string encoding: the text encoding of the file (see Section 3).

The most common modes are:

Mode Meaning
'r' read (the default); the file must exist
'w' write; the file is created, or emptied if it already exists
'a' append; writing goes to the end of the file, which is created if it does not exist
'x' create; like 'w', but fails if the file already exists

Adding 'b' to the mode (e.g. 'rb') opens the file in binary mode, where you work with bytes instead of characters. In this lab we use text mode only.

The function returns a file object. Depending on the mode, the file object can be used to read from or write to the file. When you are done with the file, close it with the close() method of the file object.

Assume we want to create a file example.txt with the following content:

Lorem ipsum dolor sit amet, consectetur adipiscing elit,
sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.
Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris
nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in
reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla
pariatur. Excepteur sint occaecat cupidatat non proident, sunt in
culpa qui officia deserunt mollit anim id est laborum.

The following code creates the file and writes the content to it. The write() method returns the number of characters written, which the shell displays:

>>> f = open('example.txt', 'w', encoding='utf-8')
>>> f.write('Lorem ipsum dolor sit amet, consectetur adipiscing elit,\n')
57
>>> f.write('sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.\n')
67
>>> f.write('Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris\n')
67
>>> f.write('nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in\n')
66
>>> f.write('reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla\n')
68
>>> f.write('pariatur. Excepteur sint occaecat cupidatat non proident, sunt in\n')
66
>>> f.write('culpa qui officia deserunt mollit anim id est laborum.\n')
55
>>> f.close()

Note that, unlike print(), write() does not add a newline: you have to write '\n' yourself.

Then the following code reads the contents of the file and prints it on the screen:

>>> f = open('example.txt', encoding='utf-8')
>>> text = f.read()
>>> f.close()
>>> print(text)
Lorem ipsum dolor sit amet, consectetur adipiscing elit,
sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.
Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris
nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in
reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla
pariatur. Excepteur sint occaecat cupidatat non proident, sunt in
culpa qui officia deserunt mollit anim id est laborum.

In the example above:

  • f is the file object,
  • f.write() writes a string to the file (the file was opened with mode 'w'),
  • f.read() reads the contents of the entire file into a string (no mode given, so the default 'r' is used),
  • f.close() closes the file.

Data written to a file is buffered, so it may not reach the disk before the file is closed. It is easy to forget close(), and the call is skipped when an error stops the program before it. The with statement closes the file automatically when its block ends, and it is the recommended way to work with files:

>>> with open('example.txt', encoding='utf-8') as f:
...     text = f.read()
...
>>> len(text)
446

How with works, and why it closes the file even after an error, is explained in Lab 6. From now on, use with in your programs.

2. Working directory

You may have noticed that the code above does not specify the full path to the file. Such a relative path is resolved against the working directory of the program: open('example.txt') looks for the file in the working directory, and open('data/example.txt') in its subdirectory data. An absolute path such as 'C:/Users/John/Documents/example.txt' (Windows) or '/home/john/example.txt' (Linux, macOS) does not depend on the working directory.

When Thonny runs a program, it first changes the working directory to the directory containing the program file. So a program and the data files it opens by a bare name should be kept in the same directory. You can check the working directory by running the following code:

>>> import os
>>> print(os.getcwd())

You can change the working directory using the os.chdir() function:

>>> os.chdir('C:/Users/John/Documents')
WarningBackslashes in Windows paths

In a string literal the backslash starts an escape sequence, as in C: '\n' is a newline and '\t' a tab. So 'C:\new\table.txt' is not the path you meant, and 'C:\Users\John' is even a syntax error (\U starts a Unicode escape). On Windows, either write paths with forward slashes, 'C:/Users/John', which Python accepts, or use a raw string, r'C:\Users\John', in which the backslash has no special meaning.

3. Text encoding

A file stores bytes, not characters. A text encoding is a mapping between characters and byte sequences, and different encodings do it in different ways. The most common encodings are:

  • ASCII: uses 7 bits per character. It can encode 128 characters: English letters, digits, punctuation and some control characters.
  • UTF-8: a variable-width encoding that can represent every character in the Unicode character set. It uses one to four bytes per character, and the ASCII characters are encoded as in ASCII, in one byte. It is the standard encoding on the web and on Linux and macOS.
  • UTF-16: another variable-width Unicode encoding, using two or four bytes per character.
  • ISO-8859-1 (Latin-1): uses 8 bits per character and can encode 256 characters, enough for Western European languages but not for Polish.
  • ISO-8859-2 (Latin-2) and Windows-1250 (cp1250): 8-bit encodings for Central European languages, including Polish. Older Polish text files on Windows are often in cp1250.

In Python, a string is converted to bytes by the str.encode() method, and bytes back to a string by bytes.decode(). A bytes literal is written with the b prefix:

>>> s = 'zażółć'
>>> len(s)
6
>>> b = s.encode('utf-8')
>>> b
b'za\xc5\xbc\xc3\xb3\xc5\x82\xc4\x87'
>>> len(b)
10
>>> b.decode('utf-8')
'zażółć'
>>> s.encode('cp1250')
b'za\xbf\xf3\xb3\xe6'

Decoding with the wrong encoding either fails or, worse, silently produces garbage (mojibake):

>>> b.decode('cp1250')
'zaĹĽĂłĹ‚Ä‡'
>>> b.decode('ascii')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
UnicodeDecodeError: 'ascii' codec can't decode byte 0xc5 in position 2: ordinal not in range(128)

When reading and writing text files, Python does exactly this behind the scenes, using the encoding given by the encoding parameter of open(). If you omit it, Python uses a default that depends on the operating system and its settings (on Polish Windows typically cp1250); only from Python 3.15 on is the default UTF-8 everywhere. A program that works on your computer may then fail on another one. Always pass encoding explicitly.

4. Reading text files

The open() function, when used with a text mode, returns a file object of the TextIOWrapper class. This is a stream object: it remembers the current position in the file, and each read continues from where the previous one ended.

The most common methods for reading from a file are read(), readline(), and readlines(), and they have the following meanings in text mode:

  • read(): reads the rest of the file into a string (optionally, you can specify the number of characters to read),
  • readline(): reads a single line from the file into a string, including the terminating '\n'; at the end of the file it returns the empty string '',
  • readlines(): reads all the remaining lines from the file into a list of strings.

For reading line by line, the for loop can be used. It is the usual way to process a text file, since only one line is held in memory at a time:

>>> with open('example.txt', encoding='utf-8') as f:
...     for line in f:
...         print(line, end='')
...
Lorem ipsum dolor sit amet, consectetur adipiscing elit,
sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.
Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris
nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in
reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla
pariatur. Excepteur sint occaecat cupidatat non proident, sunt in
culpa qui officia deserunt mollit anim id est laborum.

Each line ends with '\n' (except possibly the last line of the file), so print(line) would print an extra empty line after each line. Use print(line, end=''), or remove the newline with line.rstrip('\n').

NoteLine endings

Windows terminates lines in text files with two characters, '\r\n', while Linux and macOS use '\n' alone. In text mode Python translates both to '\n' when reading, so your program sees the same strings on every system.

5. Dictionaries

A dictionary (type dict) is a collection of key-value pairs: each key is associated with a value, and the value is looked up by its key. The keys must be unique and immutable (strings, numbers, or tuples of those; strictly speaking, hashable). The values can be of any type. Dictionaries are mutable: pairs can be added, changed and removed. Since Python 3.7, a dictionary remembers the order in which the keys were inserted.

A dictionary is implemented as a hash table, so looking up a key takes constant time on average, however large the dictionary. It corresponds to std::unordered_map in C++ and HashMap in Java, but it is built into the language and has its own syntax.

You can create a dictionary by placing a comma-separated list of key-value pairs within curly braces {}. The syntax for a key-value pair is key: value. For example:

>>> d = {'name': 'John', 'age': 30, 'city': 'New York'}
>>> d
{'name': 'John', 'age': 30, 'city': 'New York'}
>>> len(d)
3

The empty dictionary is {}. You can access the value associated with a key by using the key in square brackets. A missing key is an error; the get() method returns a default value instead (None if no default is given):

>>> d['name']
'John'
>>> d['email']
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'email'
>>> d.get('email', 'unknown')
'unknown'
>>> d.get('name', 'unknown')
'John'

The in operator checks whether a key (not a value) is in the dictionary:

>>> 'age' in d
True
>>> 'John' in d
False

You can add a new key-value pair by assigning a value to a new key; assigning to an existing key replaces its value. The del statement removes a pair:

>>> d['married'] = True
>>> d['age'] = 31
>>> d
{'name': 'John', 'age': 31, 'city': 'New York', 'married': True}
>>> del d['city']
>>> d
{'name': 'John', 'age': 31, 'married': True}

Here is an example of how to store the frequency of each character of a string in a dictionary:

>>> text = 'Lorem ipsum dolor sit amet, consectetur adipiscing elit.'
>>> freq = {}
>>> for char in text:
...     if char in freq:
...         freq[char] += 1
...     else:
...         freq[char] = 1
...
>>> freq
{'L': 1, 'o': 4, 'r': 3, 'e': 5, 'm': 3, ' ': 7, 'i': 6, 'p': 2, 's': 4, 'u': 2, 'd': 2, 'l': 2, 't': 5, 'a': 2, ',': 1, 'c': 3, 'n': 2, 'g': 1, '.': 1}

With get(), the body of the loop is a single line: freq[char] = freq.get(char, 0) + 1.

Accessing the keys, values, and key-value pairs of a dictionary can be done using the keys(), values(), and items() methods, respectively:

>>> freq.keys()
dict_keys(['L', 'o', 'r', 'e', 'm', ' ', 'i', 'p', 's', 'u', 'd', 'l', 't', 'a', ',', 'c', 'n', 'g', '.'])
>>> freq.values()
dict_values([1, 4, 3, 5, 3, 7, 6, 2, 4, 2, 2, 2, 5, 2, 1, 3, 2, 1, 1])
>>> freq.items()
dict_items([('L', 1), ('o', 4), ('r', 3), ('e', 5), ('m', 3), (' ', 7), ('i', 6), ('p', 2), ('s', 4), ('u', 2), ('d', 2), ('l', 2), ('t', 5), ('a', 2), (',', 1), ('c', 3), ('n', 2), ('g', 1), ('.', 1)])

A for loop over a dictionary goes over its keys; to get both the key and the value, iterate over items():

>>> for key, value in d.items():
...     print(f'{key}: {value}')
...
name: John
age: 31
married: True

Tuples and sorting

The pairs returned by items(), such as ('L', 1), are tuples. A tuple is an immutable sequence, written in round brackets: it can be indexed and sliced like a list, but not modified. A tuple can be unpacked into several variables, key, value = ('L', 1), which is what happens in for key, value in d.items() (and in for i, c in enumerate(...) from Lab 3). Tuples are compared lexicographically, like strings: first by the first element, and if these are equal, by the second, and so on:

>>> (2, 'b') < (3, 'a')
True
>>> (2, 'b') < (2, 'c')
True

Assume we want to see the characters of the text sorted by frequency. To this end, we can swap the keys and values, store them in a list, and then sort the list:

>>> freq_list = [(value, key) for key, value in freq.items()]
>>> freq_list.sort(reverse=True)
>>> freq_list
[(7, ' '), (6, 'i'), (5, 't'), (5, 'e'), (4, 's'), (4, 'o'), (3, 'r'), (3, 'm'), (3, 'c'), (2, 'u'), (2, 'p'), (2, 'n'), (2, 'l'), (2, 'd'), (2, 'a'), (1, 'g'), (1, 'L'), (1, '.'), (1, ',')]

Here:

  • [(value, key) for key, value in freq.items()] is a list comprehension that creates a list of tuples (value, key) from the key-value pairs in the dictionary freq.
  • freq_list.sort(reverse=True) sorts the list in place in descending order (the default is ascending order). Since the tuples are compared lexicographically, they are sorted by frequency first; characters with the same frequency are sorted by the character, also in descending order: (5, 't') comes before (5, 'e').

The built-in function sorted() works like sort(), but returns a new sorted list and leaves the original unchanged. More about sorting in Lab 7.
