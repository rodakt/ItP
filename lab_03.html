1. for loop

The for loop iterates over the items of a sequence (a list, a string, a range, …), one by one, and executes the block of code inside the loop for each item:

for item in sequence:
    statement1
    statement2
    ...

For example, the following code prints the numbers from 1 to 5:

>>> for i in range(1, 6):
...     print(i)
...
1
2
3
4
5

The loop variable may be anything the sequence contains, not only an integer:

>>> for word in ['spam', 'eggs', 'ham']:
...     print(word, len(word))
...
spam 4
eggs 4
ham 3
>>> for c in 'abc':
...     print(c.upper(), end=' ')
...
A B C
NoteNo C-style for

Python has no for (i = 0; i < n; i++) loop. The Python for is a for-each loop, like for (int x : v) in C++ or for (int x : arr) in Java; the counting loop is obtained by iterating over a range(). In particular, assigning to the loop variable inside the body does not change the course of the loop:

>>> for i in range(5):
...     i = 100
...     print(i, end=' ')
...
100 100 100 100 100

If you need both the index and the item, use enumerate():

>>> for i, c in enumerate('abc'):
...     print(i, c)
...
0 a
1 b
2 c

Loops can be nested. The inner loop runs to completion for every single iteration of the outer loop:

>>> for i in range(1, 4):
...     for j in range(1, 4):
...         print(i * j, end=' ')
...     print()
...
1 2 3
2 4 6
3 6 9

The break, continue and else statements from the previous lab work in a for loop exactly as in a while loop: break leaves the innermost loop, continue goes to the next item, and the else block runs if the loop was not left by break.

TipExercise 3.5

The aim of this exercise is to write a program monte_carlo_pi.py that estimates the value of π using the Monte Carlo method.

The idea of the Monte Carlo method is to use random numbers to estimate the value of some quantity. Imagine a square with side length 2 and a circle with diameter 2 inscribed in it. The area of the square is 4 and the area of the circle is π (draw a picture). If we randomly choose points in the square, then the ratio of the number of points inside the circle to the total number of points should be approximately equal to the ratio of the areas, i.e. π/4. Therefore:

  1. Generate a large number of random points in the square.
  2. For each point, check if it is inside the circle.
  3. Estimate π as 4 times the ratio of the number of points inside the circle to the total number of points.

The program should ask the user for the number of points to generate and then print the estimate of π and the relative error of the estimate, \(|\text{estimate} - \pi| / \pi\). The exact value is available as math.pi after import math.

Generate points using the random module (your numbers will differ):

>>> import random
>>> x = random.uniform(-1, 1)
>>> y = random.uniform(-1, 1)
>>> x, y
(0.5786150069757865, -0.9089731426425768)

Run the program for 100, 10 000 and 1 000 000 points. How does the error change?

2. String methods

Strings have many methods: functions attached to the object, called with the dot notation s.method(...). The most useful are listed below. Note that none of them changes the string s itself — strings in Python are immutable — each method returns a new string (or another value) and leaves s as it was.

>>> s = '  Hello, World!  '
>>> s.strip()                  # remove leading and trailing whitespace
'Hello, World!'
>>> s                          # s is unchanged
'  Hello, World!  '
>>> s.lower()
'  hello, world!  '
>>> s.upper()
'  HELLO, WORLD!  '
>>> s.replace('l', 'L')        # replace all occurrences
'  HeLLo, WorLd!  '
>>> s.count('l')
3
>>> s.find('World')            # index of the first occurrence, -1 if absent
9
>>> s.find('Python')
-1
>>> s.strip().startswith('Hello')
True
>>> s.strip().endswith('!')
True

Methods can be chained, as in s.strip().lower(), since each call returns a string. To check whether a substring occurs at all, the in operator is simpler than find():

>>> 'World' in s
True
>>> 'world' in s
False

Two methods convert between a string and a list of strings. str.split() cuts a string into words; without arguments it splits on any run of whitespace, with an argument it splits on exactly that separator:

>>> 'Lorem ipsum   dolor sit amet'.split()
['Lorem', 'ipsum', 'dolor', 'sit', 'amet']
>>> '2026-10-14'.split('-')
['2026', '10', '14']

str.join() is the inverse: it glues a list of strings together, using the string it is called on as the separator:

>>> words = ['Lorem', 'ipsum', 'dolor']
>>> ' '.join(words)
'Lorem ipsum dolor'
>>> '-'.join(words)
'Lorem-ipsum-dolor'
>>> ''.join(['a', 'b', 'c'])
'abc'

Finally, a few methods test what a string consists of:

>>> 'abc'.isalpha(), 'ab1'.isalpha()
(True, False)
>>> '123'.isdigit(), '12.3'.isdigit()
(True, False)
>>> 'a'.islower(), 'A'.isupper()
(True, True)

The full list is in the documentation: String Methods.

WarningStrings are immutable

In C a string is an array of char and you can write s[0] = 'J'. In Python this is an error:

>>> s = 'hello'
>>> s[0] = 'J'
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'str' object does not support item assignment

A “modified” string is always a new string. Build it from pieces ('J' + s[1:]), with a method (s.replace('h', 'J')), or — in a loop — by appending to a result string with += or by collecting the pieces in a list and calling ''.join() at the end.

3. ord() and chr() functions

Each character has a number: its Unicode code point. For the English letters, digits and punctuation these are the ASCII codes you know from C. The ord() function returns the code point of a one-character string, and chr() is its inverse:

>>> ord('A')
65
>>> chr(65)
'A'
>>> ord('a') - ord('A')
32
>>> chr(ord('A') + 1)
'B'
>>> ord('ł')
322

Letter arithmetic in Python is therefore done through ord() and chr(): unlike in C, 'A' + 1 is an error, since a one-character string is still a string, not a number.

TipExercise 3.10

Write a program caesar_cipher.py that reads a string and an integer n from the user and prints the Caesar cipher encoding of the string. The Caesar cipher replaces each letter in the input string with the letter n positions ahead in the alphabet. For example, if n is 3, A is replaced with D, B with E, and so on. The case of a letter is preserved: a is replaced with d, b with e. If the new position goes beyond the end of the alphabet, it wraps around to the beginning (Z with n = 3 becomes C). Non-alphabetic characters, such as spaces, digits or punctuation marks, are left unchanged.

Example:

>>> %Run caesar_cipher.py
Enter a string: Hello, World!
Enter a number: 3
Khoor, Zruog!
>>> %Run caesar_cipher.py
Enter a string: Khoor, Zruog!
Enter a number: -3
Hello, World!

Hint: for a lowercase letter c, the shifted letter is chr((ord(c) - ord('a') + n) % 26 + ord('a')). The % operator takes care of the wrap-around, also for negative n (check -3 % 26 in the shell).
