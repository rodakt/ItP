1. Writing programs

In Thonny, you write programs in the editor. A program is saved in a file with the .py extension. You run it by clicking the Run button or by pressing F5; the output appears in the shell. You can also run a program from the Thonny shell by typing

>>> %Run program_name.py

where program_name.py is the name of the file with the program. This works in the Thonny shell only. In the system shell (terminal), run the program with

$ python3 program_name.py

(on Windows the command is usually python or py instead of python3).

Note that a Python program needs no main() function: the statements in the file are simply executed from top to bottom.

2. Input and output

Python provides two built-in functions for writing text to the standard output and reading text from the standard input: print() and input().

The print() function takes zero or more positional arguments and writes them to the standard output. The arguments can be of any type; they are converted to strings before being written.

>>> print('Hello, world!')
Hello, world!
>>> print(42)
42
>>> print("The answer is", 42)
The answer is 42
>>> print([1, 2, 3])
[1, 2, 3]

The input() function writes its (optional) argument as a prompt, reads a line from the standard input and returns it as a string, without the trailing newline.

>>> name = input('What is your name? ')
What is your name? Tom
>>> name
'Tom'

Do not use loops in this exercise. Instead, use:

  • concatenation and multiplication of strings;
  • the len() function. It takes a string or, more generally, a collection, and returns the number of its elements.

print() has some optional keyword arguments that let you control the output format. The most important are:

  • sep — the string written between the arguments; the default is a single space;
  • end — the string written after the last argument; the default is a newline character '\n'.
>>> print(1, 2, 3)
1 2 3
>>> print(1, 2, 3, sep=', ')
1, 2, 3
>>> print(1, 2, 3, end='; '); print(4)
1 2 3; 4

The input() function always returns a string. If you want to read a number, you have to convert the string to a number with int() or float():

>>> n = int(input('Enter a number: '))
Enter a number: 42
>>> n
42
>>> x = float(input('Enter a number: '))
Enter a number: 3.14
>>> x
3.14

If the argument cannot be converted, int() and float() raise a ValueError exception and the program stops with an error message:

>>> int('3.14')
Traceback (most recent call last):
  ...
ValueError: invalid literal for int() with base 10: '3.14'

Handling such errors comes later in the course. In this lab, assume that the user always enters valid data, unless an exercise says otherwise.

Warninginput() returns a string

Forgetting the conversion does not always cause an error. Sometimes the program just quietly computes something else:

>>> a = input('Enter a number: ')
Enter a number: 42
>>> b = input('Enter a number: ')
Enter a number: 13
>>> a + b
'4213'
>>> '9' > '10'
True

+ on strings is concatenation, and strings are compared character by character ('9' > '1'). Mixing types fails only when the operation makes no sense, e.g. '9' > 10 raises a TypeError.

Formatted string literals (f-strings)

A string literal prefixed with f may contain expressions in braces { }. They are evaluated and their values are inserted into the string:

>>> name = 'Tom'
>>> age = 42
>>> f'{name} is {age} years old.'
'Tom is 42 years old.'
>>> f'Next year {name} will be {age + 1}.'
'Next year Tom will be 43.'

After a colon, you can add a format specification, which works much like the format strings of printf() in C:

>>> x = 2 / 3
>>> f'{x:.2f}'          # 2 digits after the decimal point, like %.2f
'0.67'
>>> f'[{age:5d}]'       # integer, field width 5, like %5d
'[   42]'
>>> f'[{name:>6}]'      # right-aligned in a field of width 6
'[   Tom]'
>>> f'[{name:<6}]'      # left-aligned
'[Tom   ]'
>>> f'[{name:^7}]'      # centred
'[  Tom  ]'

An = after the expression prints both the expression and its value, which is handy for debugging:

>>> f'{age + 1 = }'
'age + 1 = 43'

The full syntax is described in the Format Specification Mini-Language.

3. Conditional statements

Python provides the if statement for conditional execution. Its syntax is:

if condition:
    statement1
    statement2
    ...

The condition is an expression whose truth value is checked (it need not be a bool; see Truthiness in Lab 1). If it is true, the statements are executed; otherwise they are skipped.

>>> x = 42
>>> if x == 42:
...     print('The answer to the ultimate question of life, the universe, and everything.')
...
The answer to the ultimate question of life, the universe, and everything.

In the shell, a compound statement is finished by an empty line.

The statements that form the body of if must be indented. The standard indentation is four spaces. You can use tabs instead, but it is not recommended, and mixing tabs and spaces is an error.

NoteIndentation instead of braces

In C, C++ and Java, indentation is only a matter of style and blocks are delimited by { }. In Python, indentation is the syntax: it alone determines which statements belong to the block. Note also that the condition needs no parentheses, but the header line must end with a colon :.

The if statement can be followed by an else clause:

if condition:
    statement1
    statement2
    ...
else:
    statement3
    statement4
    ...

If the condition is true, the statements after if are executed. Otherwise, the statements after else are executed.

>>> x = 13
>>> if x % 2 == 0:
...     print('The number is even.')
... else:
...     print('The number is odd.')
...
The number is odd.

The if statement can be followed by zero or more elif clauses:

if condition1:
    statement1
    statement2
    ...
elif condition2:
    statement3
    statement4
    ...
elif condition3:
    statement5
    statement6
    ...
else:
    statement7
    statement8
    ...

elif is short for “else if”. The conditions are checked in order; the statements after the first true condition are executed and the rest is skipped. If none of the conditions is true, the statements after else (if present) are executed.

>>> x = 42
>>> if x < 0:
...     print('The number is negative.')
... elif x == 0:
...     print('The number is zero.')
... else:
...     print('The number is positive.')
...
The number is positive.

4. while loop

Python provides the while statement for indefinite iteration. Its syntax is:

while condition:
    statement1
    statement2
    ...

The condition is checked before each pass through the loop. If it is true, the statements are executed and the condition is checked again; as soon as it is false, the loop ends and the program continues after it.

>>> n = 0
>>> while n < 5:
...     print(n)
...     n += 1
...
0
1
2
3
4

You may think of the while statement as a repeated if statement: if executes its body at most once, while while executes it as long as the condition stays true.

Python has no ++ and -- operators; use n += 1 and n -= 1 instead.

WarningStopping an infinite loop

If you forget to change the variable tested in the condition (e.g. you leave out n += 1 above), the loop never ends. In Thonny, stop the program with the Stop button or Ctrl+F2; in the system terminal, press Ctrl+C.

5. break and continue statements

The break statement terminates the innermost enclosing loop (while, or for — see the next lab); the program continues with the statement after the loop.

>>> n = 0
>>> while True:
...     print(n)
...     n += 1
...     if n == 5:
...         break
...
0
1
2
3
4

The continue statement skips the rest of the loop body and goes on to the next iteration (for while, the condition is checked again).

>>> n = 0
>>> while n < 5:
...     n += 1
...     if n % 2 == 0:
...         continue
...     print(n)
...
1
3
5
NoteNo do ... while

Python has no do ... while loop known from C, C++ and Java. A loop whose body must run at least once, e.g. “read a number, stop when it is 0”, is written as while True: with a break inside.

else clause of a loop

A while loop may have an else clause. Its body is executed when the loop ends normally, i.e. because the condition became false, but not when the loop is left with break:

n = 91
d = 2
while d * d <= n:
    if n % d == 0:
        print(n, 'is divisible by', d)
        break
    d += 1
else:
    print(n, 'is prime')

For n = 91 the program writes 91 is divisible by 7; for n = 97 it writes 97 is prime.

NoteLoop else instead of a flag

C, C++ and Java have no such construct; there you would typically introduce a Boolean flag (found = false;), set it before break and test it after the loop. In Python, the loop else does this for you. The name is admittedly confusing: read it as “no break”.
