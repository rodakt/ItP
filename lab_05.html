1. Defining functions

A function is a named block of code that performs a computation. You have already used many built-in functions, such as print(), len() or range(); now you will write your own.

A function is defined with the def keyword, followed by the name of the function, the list of its parameters in round brackets and a colon. The body of the function is the indented block below. The return statement ends the function and gives back a value to the caller:

>>> def add(a, b):
...     return a + b
...
>>> add(2, 3)
5
>>> add('abc', 'def')
'abcdef'
>>> add([1, 2], [3])
[1, 2, 3]

Unlike in C, C++ and Java, neither the parameters nor the result have declared types: add() works for any values that can be added with +. There are no prototypes or header files either. def is an ordinary statement, executed when the program reaches it, and it creates a function object bound to the name add. So a function must be defined before the line that calls it is executed, but it may call other functions that are defined later in the file.

The return statement does not have to be the last statement of the body; it may occur anywhere, also inside a loop, and the function ends as soon as it is executed. A function that ends without return (or with a bare return) returns the special value None. The shell does not display None:

>>> def greet(name):
...     print(f'Hello, {name}!')
...
>>> greet('Ann')
Hello, Ann!
>>> result = greet('Ann')
Hello, Ann!
>>> print(result)
None
>>> result is None
True
Warningprint() is not return

greet() prints a value, it does not return it. In the shell the two look alike, since the shell displays the value of an expression you type, but a printed value cannot be used in further computation: greet('Ann') + '!' is an error. Unless an exercise asks you to print something, the functions in this lab should return their results and print nothing.

2. Returning several values

A function returns a single object, but that object may be a tuple (Lab 4). Together with tuple unpacking, this lets a function return several values. For example, the built-in function divmod(a, b) returns the quotient and the remainder of integer division:

>>> divmod(17, 5)
(3, 2)
>>> q, r = divmod(17, 5)
>>> q
3

The round brackets around a returned tuple may be omitted:

>>> def min_max(numbers):
...     return min(numbers), max(numbers)
...
>>> low, high = min_max([3, 1, 4, 1, 5, 9, 2, 6])
>>> low, high
(1, 9)

In C you would return such results through pointer parameters, in Java through an array or a small class.

3. Arguments

Keyword arguments and default values

An argument can be passed by position or by the name of the parameter, as a keyword argument. Keyword arguments may come in any order, but after all the positional ones:

>>> def describe(name, age, city):
...     return f'{name}, {age}, from {city}'
...
>>> describe('John', 30, 'Boston')
'John, 30, from Boston'
>>> describe('John', city='Boston', age=30)
'John, 30, from Boston'

A parameter may have a default value, used when the argument is omitted. Parameters with default values must come after those without:

>>> def power(x, exponent=2):
...     return x ** exponent
...
>>> power(5)
25
>>> power(5, 3)
125
>>> power(x=2, exponent=10)
1024

You have already used both features: print(x, end='') (Lab 3) passes the keyword argument end, whose default value is '\n', and list.sort(reverse=True) (Lab 4) passes reverse, whose default is False. Keyword arguments make a call readable: sort(reverse=True) says more than a bare True would.

Passing objects to functions

In Python, a variable is a name for an object (Lab 1), and passing an argument binds the parameter to the same object, without copying it. If the function modifies a mutable object, such as a list or a dictionary, the change is visible to the caller. If the function assigns a new object to the parameter, only the local name changes:

>>> def append_zero(lst):
...     lst.append(0)
...
>>> def replace(lst):
...     lst = [0]
...
>>> numbers = [1, 2]
>>> append_zero(numbers)
>>> numbers
[1, 2, 0]
>>> replace(numbers)
>>> numbers
[1, 2, 0]

This works like passing references to objects in Java, or pointers in C: through the pointer you can change the pointed-to object, but assigning a new address to the pointer parameter does not affect the caller. Immutable objects, such as numbers, strings and tuples, cannot be changed at all, so for them the result is as if they were passed by value.

WarningMutable default values

A default value is computed once, when the def statement is executed, not at every call. A mutable default, such as def add_item(item, items=[]), is therefore a single list shared by all the calls that use the default, and it grows from call to call. Use None as the default instead and create the list inside the function: if items is None: items = [].

Local and global variables

A variable assigned inside a function, including a parameter, is local: it exists only while the function runs and is not visible outside it. A function can read the variables of the file (global variables), but an assignment to a name anywhere in a function makes that name local in the whole body of the function:

>>> x = 10
>>> def show():
...     print(x)
...
>>> show()
10
>>> def change():
...     print(x)
...     x = 1
...
>>> change()
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "<stdin>", line 2, in change
UnboundLocalError: cannot access local variable 'x' where it is not associated with a value

To assign to a global variable inside a function, declare it with global x at the beginning of the body. Do this sparingly: a function that communicates only through its parameters and its return value is easier to understand and to test.

4. Recursion

A function may call itself. Such a function is recursive. A recursive definition needs a base case, solved directly, and a recursive case, which reduces the problem to a smaller instance of the same problem. A classic example is the factorial, \(n! = 1\) for \(n = 0\) and \(n! = n \cdot (n-1)!\) for \(n > 0\):

>>> def factorial(n):
...     if n == 0:
...         return 1
...     return n * factorial(n - 1)
...
>>> factorial(5)
120
>>> factorial(30)
265252859812191058636308480000000

Each call waiting for the result of a recursive call occupies a frame on the call stack. To prevent a stack overflow, which in C ends with a crash, Python limits the depth of recursion, by default to about 1000 calls; factorial(5000) ends with RecursionError: maximum recursion depth exceeded. Python also does not optimise tail calls. So recursion in Python is fine for problems that are naturally recursive and not too deep, but a simple loop is usually better written as a loop.

5. Docstrings and the doctest module

A docstring is a string literal that is the first statement of a function (or of a file, or of a class). It documents what the function does. By convention it is written in triple double quotes, which allow several lines: the first line is a short summary, followed by an empty line and the details. The docstring is shown by help():

>>> def add(a, b):
...     """Return the sum of a and b."""
...     return a + b
...
>>> help(add)
Help on function add in module __main__:

add(a, b)
    Return the sum of a and b.

A docstring may contain examples written as a shell session. The doctest module finds such examples, executes them and checks that the results are exactly as shown. So the examples document the function and test it at the same time. Save the following program as add.py and run it:

def add(a, b):
    """Return the sum of a and b.

    >>> add(2, 3)
    5
    >>> add('abc', 'def')
    'abcdef'
    """
    return a + b


if __name__ == '__main__':
    import doctest
    doctest.testmod(verbose=True)

The program prints each example it tries, whether it passed, and a summary ending with Test passed. Without verbose=True, testmod() prints nothing when all the tests pass, and only reports the failures. Change 5 to 6 in the docstring and run the program again to see a failure report.

The condition __name__ == '__main__' is true when the file is run as a program, and false when it is imported as a module by another file; so the tests are run only when you run the file itself. Lab 6 makes use of this.

NoteWhat a doctest compares

doctest compares the text the shell would display, character by character. So the expected value of a string is written with quotes, 'abcdef'; a result None is written as nothing at all; and a dictionary must be written with its keys in insertion order. A float result such as 0.1 + 0.2 is displayed as 0.30000000000000004; test round(x, 2) or abs(x - y) < 1e-9 instead.
