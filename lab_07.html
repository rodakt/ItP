1. Functions are objects

In Lab 5 you saw that def creates a function object and binds it to a name. A function is an object like any other: it can be bound to another name, stored in a list or a dictionary, passed as an argument to another function and returned from a function. The name of a function, without round brackets, refers to the function object; the brackets call it:

>>> len
<built-in function len>
>>> size = len
>>> size('abc')
3
>>> data = [3, 1, 4, 1, 5]
>>> for f in [min, max, sum, len]:
...     print(f.__name__, f(data))
...
min 1
max 5
sum 14
len 5

A function that takes another function as an argument, or returns a function as its result, is called a higher-order function. This lab is about the higher-order functions of the standard library, which take a function as an argument; in Lab 8 you will write your own.

In C you would pass a pointer to a function, as in the comparison function of qsort(); in Java, an object implementing an interface such as Comparator, usually written as a lambda expression. In Python no special syntax is needed: you pass the function itself.

WarningPass the function, not its result

key=len passes the function len; key=len() calls len without arguments, which is an error, and key=len(word) passes a number. The function you pass is called by the higher-order function, as many times as it needs.

2. max() and min() with a key function

The max() and min() functions return the largest and the smallest element of an iterable. The optional keyword argument key is a function of one argument. If it is given, the elements are compared by the values key(element) instead of by themselves, but the element itself is returned:

>>> def neg(x):
...     return -x
...
>>> max([1, 2, 3, 4, 5])
5
>>> max([1, 2, 3, 4, 5], key=neg)
1
>>> words = 'Lorem ipsum dolor sit amet'.split()
>>> max(words)
'sit'
>>> max(words, key=len)
'Lorem'
>>> max(words, key=str.lower)
'sit'
>>> min(words, key=str.lower)
'amet'

The result of max(words) is 'sit', because strings are compared by the codes of their characters (Lab 3) and lowercase letters come after uppercase ones; key=str.lower compares the words ignoring case. If several elements have the same largest key, max() returns the first of them: here 'Lorem', 'ipsum' and 'dolor' all have length 5.

For an empty iterable, max() and min() raise ValueError. The keyword argument default gives the value to be returned in that case instead: max([], default=None) is None.

3. Sorting with a key function

The built-in function sorted() returns a new sorted list of the elements of any iterable; the method list.sort() sorts a list in place and returns None (Lab 4). Both accept the keyword arguments key, with the same meaning as in max(), and reverse, which sorts in descending order when True:

>>> sorted([3, 1, 2])
[1, 2, 3]
>>> sorted([3, 1, 2], key=neg)
[3, 2, 1]
>>> sorted(words)
['Lorem', 'amet', 'dolor', 'ipsum', 'sit']
>>> sorted(words, key=str.lower)
['amet', 'dolor', 'ipsum', 'Lorem', 'sit']
>>> sorted(words, key=len)
['sit', 'amet', 'Lorem', 'ipsum', 'dolor']
>>> sorted(words, key=len, reverse=True)
['Lorem', 'ipsum', 'dolor', 'amet', 'sit']
>>> a = [1, 3, 2, 5, 4]
>>> a.sort(key=neg)
>>> a
[5, 4, 3, 2, 1]

The key function is called exactly once for each element, and the elements are then sorted by the computed keys. If a key is a tuple, the elements are sorted by its first component, then by the second, and so on (Lab 4), which makes it easy to sort by several criteria at once.

Sorting in Python is stable: elements with equal keys keep their original relative order. That is why 'Lorem', 'ipsum' and 'dolor' above are in the order in which they occur in words, with reverse=True too: reverse reverses the comparisons, not the result, so it is not the same as reversing the sorted list.

NoteKey functions instead of comparison functions

The comparison function of C’s qsort() or of Java’s Comparator takes two elements and tells which of them comes first. Python’s sorted() takes a key function of one element instead, which is simpler to write and calls the function \(n\) times rather than \(O(n \log n)\) times. If you really have a comparison function, functools.cmp_to_key() converts it into a key function.

4. filter() and map()

The function filter(function, iterable) gives the elements of iterable for which function(element) is true (in the sense of Lab 1, so any truthy value counts). The function map(function, iterable) gives the results function(element) for all the elements:

>>> def is_even(x):
...     return x % 2 == 0
...
>>> list(filter(is_even, range(10)))
[0, 2, 4, 6, 8]
>>> list(filter(None, [0, 1, '', 'a', [], [0]]))
[1, 'a', [0]]
>>> list(map(len, words))
[5, 5, 5, 3, 4]
>>> list(map(str.upper, words))
['LOREM', 'IPSUM', 'DOLOR', 'SIT', 'AMET']

With None instead of a function, filter() keeps the truthy elements. Given several iterables, map() calls a function of several arguments with one element of each: list(map(pow, [2, 3, 4], [3, 2, 1])) is [8, 9, 4].

Unlike sorted(), neither filter() nor map() returns a list. They return iterators, objects that compute the next element only when it is requested, e.g. by a for loop, by list() or by sum(). An iterator can be traversed only once:

>>> lengths = map(len, words)
>>> lengths
<map object at 0x7f1c2a3b4e50>
>>> sum(lengths)
22
>>> sum(lengths)
0

More about iterators in Lab 11.

The same results can be obtained with list comprehensions (Lab 1): [x for x in range(10) if is_even(x)] and [len(w) for w in words]. Comprehensions are usually preferred when the function would have to be written just for that purpose; map() and filter() are handy when it already exists, as len or str.upper above. A common idiom reads several numbers from one line:

>>> numbers = list(map(int, input('Numbers: ').split()))
Numbers: 3 1 4 1 5
>>> numbers
[3, 1, 4, 1, 5]

5. lambda expressions

Key functions and predicates are often so short that defining them with def is cumbersome. A lambda expression creates a function without a name:

>>> sorted(words, key=lambda w: w[-1])
['Lorem', 'ipsum', 'dolor', 'sit', 'amet']
>>> list(filter(lambda n: n % 3 == 0, range(20)))
[0, 3, 6, 9, 12, 15, 18]
>>> points = [(1, 5), (3, 2), (2, 8)]
>>> max(points, key=lambda p: p[1])
(2, 8)

lambda x, y: x + y is a function of two parameters that returns x + y, equivalent to

def add(x, y):
    return x + y

The body of a lambda is a single expression, whose value is returned; it cannot contain statements such as assignments, if or for statements, or return. A conditional expression (Lab 1) is allowed: lambda x: x if x >= 0 else -x.

Use lambda where a function is passed as an argument. Do not assign a lambda to a name: square = lambda x: x ** 2 works, but def square(x): return x ** 2 does the same, gives the function a name shown in tracebacks instead of <lambda>, and allows a docstring (the PEP 8 style guide recommends def here).

6. functools.reduce()

The function reduce(function, iterable[, initial]) of the functools module combines the elements of an iterable into a single value with a function of two arguments. It applies the function to the first two elements, then to the result and the third element, and so on, from left to right:

>>> from functools import reduce
>>> def add(x, y):
...     return x + y
...
>>> reduce(add, [1, 2, 3, 4, 5])
15
>>> reduce(add, [1, 2, 3, 4, 5], 100)
115
>>> reduce(lambda x, y: 10 * x + y, [1, 2, 3, 4])
1234

The first call computes add(add(add(add(1, 2), 3), 4), 5), the last ((1 * 10 + 2) * 10 + 3) * 10 + 4. If the third argument initial is given, it is placed before the elements, and it is the result for an empty iterable; without it, reduce() of an empty iterable raises TypeError. The documentation shows the equivalent pure Python code.

reduce() is general, but rarely the most readable choice. For the most common reductions there are dedicated functions: sum(), max(), min(), any(), all(), math.prod() and str.join().
